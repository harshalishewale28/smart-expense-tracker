# 💰 SpendWise – Smart Expense Tracker

SpendWise is a responsive web-based expense tracking application designed to help users manage their personal finances. It allows users to track income and expenses, set monthly budgets, analyze spending patterns, and monitor their financial activities through an interactive dashboard.

## 🚀 Features

- **Dashboard:** View total balance, income, expenses, and budget overview.
- **Transaction Management:** Add, edit, and delete income and expense transactions.
- **Monthly Budget Planner:** Set monthly budgets and track spending progress.
- **Analytics:** Visualize financial activities using interactive charts.
- **Category Insights:** Understand spending by category.
- **Search & Filters:** Search transactions and filter by type or month.
- **Dark/Light Mode:** Switch between themes.
- **CSV Export:** Export transaction records.
- **Local Storage:** Save data in your browser.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.

## ⚙️ How to Run the Project

1. Clone your GitHub repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd SpendWise
   ```

3. Open the folder in VS Code:

   ```bash
   code .
   ```

4. Open `index.html` using the VS Code Live Server extension.

5. Start managing your income and expenses!

## 📊 Project Modules

### 1. Dashboard
Displays total balance, income, expenses, budget status, and recent transactions.

### 2. Transactions
Allows users to add, edit, delete, search, and filter financial transactions.

### 3. Monthly Budget
Helps users set a monthly spending limit and monitor budget usage.

### 4. Analytics
Displays charts and category-wise spending information to help users understand their financial habits.

## 💾 Data Storage

SpendWise uses browser Local Storage to save transaction and budget information.

**Note:** Data is stored in the current browser. It is not automatically synchronized across devices or backed up to a cloud server.

## 🌐 Deployment

You can deploy this project using GitHub Pages:

1. Open your GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/root`.
6. Click **Save**.

GitHub Pages will provide a website link after deployment.
