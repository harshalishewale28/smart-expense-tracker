
# 💰 Smart Expense Tracker

A responsive personal finance dashboard built using HTML, CSS, and JavaScript to help users track income, manage expenses, and monitor their spending.

## 🚀 Features

- ➕ Add income and expense transactions
- ✏️ Edit existing transactions
- 🗑️ Delete transactions
- 💵 Automatically calculate total income, expenses, and balance
- 🔍 Search transactions by description or category
- 🗂️ Filter transactions by income or expense
- 📊 View category-wise spending summaries
- 💾 Save transaction data using browser localStorage
- 📱 Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling and responsive design
- JavaScript — Functionality and calculations
- Browser localStorage — Data persistence
- Git and GitHub — Version control and project hosting

## ⚙️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/smart-expense-tracker.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Alternatively, open the folder in VS Code and run `index.html` using the Live Server extension.

## 🔐 Data Storage

Transaction data is saved in the browser's localStorage. Data is stored locally in the browser and is not synchronized across devices or accounts.

This project is intended for learning and personal expense tracking. Avoid entering sensitive financial information.

## 🎯 Project Objective

The goal of this project is to develop a simple, user-friendly expense management application while practicing frontend development, JavaScript programming, DOM manipulation, and browser storage.
